# Guilherme Simioni Bonfim

I'm an electrical engineering undergraduate at Stanford. I work on drones and autonomy as an officer of Stanford Student Robotics, where I build with the SkyRunners drone team, and I also work on photonics and hardware.

## Projects

- [FLAMBE](https://github.com/guinterface/flambe) studies how drones can navigate with vision when GPS is unavailable.
- [SkyRunners Ridgeback](https://github.com/guinterface/skyrunners-ridgeback) is our club's VTOL drone design, with CAD, structural checks, build sheets and a project site.
- The [CryoLink water rig](https://github.com/guinterface/cryolink-water-rig) uses water to test a propellant coupling and includes the build book, CAD, simulations and firmware.
- [Ozires](https://github.com/guinterface/Ozires) is a reinforcement learning course project where I implemented custom PPO for drone navigation.
- [neuro-architectura](https://github.com/guinterface/neuro-architectura) looks at how EEG signals can be used to decode responses to images of architecture.
